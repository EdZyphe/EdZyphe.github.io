# Portfolio de Pierre Weill — source

Site statique (HTML/CSS/JS, sans dépendance) publié sur GitHub Pages.

- `index.html`, `style.css`, `script.js`, `favicon.svg` : le site
- `fonts/` : Besley et Archivo, hébergées ici (licence SIL OFL 1.1, voir `fonts/OFL-*.txt`)
- `media/` : images optimisées (WebP, variantes 320/640/1200 px et original jusqu'à 2000 px, provenance dans les fichiers `.json` voisins) et vidéos ré-encodées (H.264, son normalisé vers -14 LUFS)
- Sources haute définition conservées hors de ce dépôt.

Prévisualiser : `python3 -m http.server` dans ce dossier, puis http://localhost:8000
